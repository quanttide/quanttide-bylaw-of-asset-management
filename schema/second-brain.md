# 量潮第二大脑资产章程

## 第一章 总则

**第一条** GitHub 公开仓库是量潮知识资产的主要形态：九宫格各资产类型（Bylaw、Journal、Profile 等）均以公开仓库为载体。

**第二条** 本章程规定量潮 GitHub 组织下各仓库的命名规则，为仓库命名、目录结构与挂载路径提供依据。

**第三条** 资产图式（九宫格资产类型）等概念定义见《量潮第二大脑章程》（quanttide-bylaw-of-philosophy/memory/second-brain.md），本章程不再重复。

## 第二章 仓库命名

**第四条** 领域仓库命名：`quanttide-{领域短名}`，如 `quanttide-agent`、`quanttide-crowd`、`quanttide-learn`。

**第五条** 资产子仓库命名：`quanttide-{资产类型}-of-{领域英文名}`，如 `quanttide-journal-of-crowd-sourcing`、`quanttide-bylaw-of-document-engineering`。

**第六条** 法人主体资产命名：`quanttide-{资产类型}-of-business-entity`，如 `quanttide-profile-of-business-entity`。

**第七条** 聚合容器命名：`quanttide-{资产类型}`，如 `quanttide-journal`、`quanttide-profile`、`quanttide-roadmap`、`quanttide-bylaw`。

**第八条** 应用命名：`qt{产品名}` 或 `qtcloud-{产品名}`，如 `qtcrowd`、`qtclass`、`qtcloud-learn`。

**第九条** 工具集命名：`quanttide-{领域}-toolkit`，如 `quanttide-crowd-toolkit`。

**第十条** 实验室命名：`quanttide-laboratory-of-{领域英文名}`，如 `quanttide-laboratory-of-crowdsourcing-management`。

## 第三章 挂载路径

**第十一条** 领域仓库内挂载路径：`apps/` 挂应用，`packages/` 挂工具集，`examples/default` 挂实验室，`data/` 与 `docs/` 按资产类型挂载对应子仓库。

## 第四章 附则

**第十二条** 本章程由资产治理团队维护和修订。
