# 量潮公开平台资产契约章程

## 第一章 总则

**第一条** 量潮公开平台资产是量潮产品与服务的基础设施载体，分为 Git 仓库与 S3 存储桶两大类。本章程规定公开平台资产的定义、类别与维护规范。

**第二条** 公开平台资产必须遵循"类别明确、上架可控"的原则，禁止资产长期停留在未分类状态（如 `others` 分类）。

## 第二章 类别

**第三条** 公开平台资产按业务归属划分类别，类别以业务线前缀命名，如 `qtclass-`（量潮课堂）、`qtdata-`（量潮数据）、`qtcrowd-`（量潮众包）、`qtcloud-`（量潮云平台）等。

## 第三章 Git 仓库

**第四条** Git 仓库承载平台应用的源代码与配置，一个平台一个仓库，以平台名命名，如 `qtclass`（量潮课堂）。

## 第四章 S3 存储桶

**第五条** S3 存储桶承载平台的部署产物与业务数据，按 `{业务线前缀}-{桶类型}` 命名，包括：

- Site 首页（`{业务线}-site`，如 `qtclass-site`）：React 首页部署产物
- Studio 工作台（`{业务线}-studio`，如 `qtclass-studio`）：Flutter 客户端部署产物
- Provider 平台数据（`{业务线}-provider`，如 `qtclass-provider`）：平台维护的正式数据
- Private 内部数据（`{业务线}-private`，如 `qtclass-private`）：未上架的业务数据、备份

**第六条** S3 存储桶分类规则：

- 内部数据存储桶（`*-private`）用于存放未上架的业务数据
- 平台数据存储桶（`*-provider`）用于存放平台维护的正式数据
- 业务数据上架时，从内部数据存储桶转移到对应的平台数据存储桶

## 第五章 附则

**第七条** 本章程由资产治理团队维护和修订。

**第八条** 本章程自发布之日起生效，适用于所有新建和存量公开平台资产。
