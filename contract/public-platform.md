# 量潮公开平台资产契约章程

## 第一章 总则

**第一条** 量潮公开平台资产是量潮产品与服务的基础设施载体，分为 Git 仓库与 S3 存储桶两大类。本章程规定公开平台资产的定义、分类、生命周期与维护规范。

**第二条** 公开平台资产必须遵循"分类明确、生命周期清晰、上架可控"的原则，禁止资产长期停留在未分类状态（如 `others` 分类）。

## 第二章 类别

**第三条** 公开平台资产按业务归属划分类别，类别以业务线前缀命名，如 `qtclass-`（量潮课堂）、`qtdata-`（量潮数据）、`qtcrowd-`（量潮众包）、`qtcloud-`（量潮云平台）等。

## 第四章 S3 存储桶规范

**第八条** S3 存储桶用于存放静态资源、部署产物、用户数据等非版本化资产，包括：
- **Site 首页**：React首页部署产物
- **Studio 工作台**：Flutter客户端部署产物
- **Provider 服务端**：API 静态资源、上传文件
- **Private 私有数据**：未上架的业务数据、备份

**第九条** S3 存储桶命名必须遵循 `{业务线前缀}-{用途}` 格式：

| 用途 | 命名模式 | 示例 |
|:----|:----|:----|
| Site 首页 | `{业务线}-site` | `qtclass-site` |
| Studio 工作台 | `{业务线}-studio` | `qtclass-studio` |
| Provider 平台数据 | `{业务线}-provider` | `qtclass-provider` |
| Private 内部数据 | `{业务线}-private` | `qtclass-private` |


**第十条** S3 存储桶分类规则：

- 内部数据存储桶（`*-private`）用于存放未上架的业务数据
- 平台数据存储桶（`*-provider`）用于存放平台维护的正式数据

## 第五章 附则

**第十二条** 本章程由资产治理团队维护和修订。

**第十三条** 本章程自发布之日起生效，适用于所有新建和存量公开平台资产。
